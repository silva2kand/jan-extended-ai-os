## Project Structure

```
real-everything-app/
├── backend/                    # FastAPI Python backend
│   ├── main.py                # API entry point
│   ├── orchestrator/          # Task planning & execution
│   ├── agents/                # Domain agents (solicitor, accountant, coding, ops)
│   ├── generative_agent/      # Self-building tools
│   ├── tools/                 # Tool registry & execution
│   ├── connectors/           # External services (Outlook, Gmail, WhatsApp, etc.)
│   ├── sandbox/              # Safe code execution
│   ├── models/                # LLM routing (Ollama, LM Studio, Gemini, OpenRouter, Groq)
│   └── db/                   # SQLite database
├── desktop-app/               # WPF .NET 8 desktop app
│   ├── MainWindow.xaml       # Full chat UI with Edit/Copy/Speak/Continue/Regenerate
│   ├── BubbleWindow.xaml     # Small always-on-top assistant
│   ├── Services/             # Backend client, TTS, Context engine
│   └── Converters/           # Status/Risk color converters
└── shared/                   # JSON schemas & config
```

## Key Features

### Backend
- **POST /chat** - Main chat endpoint with context awareness
- **GET /models** - Auto-detect Ollama/LM Studio, connect remote APIs
- **Tool Registry** - Execute tools with permission system
- **Connectors** - Outlook, Gmail, WhatsApp, Browser, Calendar, Terminal, FileSystem
- **Orchestrator** - Task planning, execution, summarization
- **Generative Agent** - Creates new tools on demand
- **Domain Agents** - Solicitor, Accountant, Coding, Ops specialists

### Desktop App
- **Chat Interface** with Edit, Copy, Speak (TTS), Continue, Regenerate buttons
- **Model Selector** - Switch between local and remote models
- **System Tray** - Minimize to tray, bubble assistant popup
- **Always-on-top Bubble** - Quick actions (Summarize, Email, Tasks, Search)
- **Tabbed Interface** - Chat, Models, Tools, Connectors, Agents
- **Context Engine** - Active window detection, clipboard monitoring
